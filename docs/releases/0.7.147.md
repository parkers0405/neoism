# Neoism v0.7.147

This stable update fixes glyph-cache contamination that can make GPUIX Agent text show a mixture of normal and bold letters within the same word.

## Fixes

- Include synthetic bold and italic styles in glyph bitmap cache keys. A letter drawn with one synthesized style can no longer contaminate later text using the same font, glyph, and size with another style.
- Add a pixel-level regression covering both rendering orders: plain text after synthesized bold, and synthesized bold after plain text. The regression failed before the correction and passed afterward.

## Verification and scope

The cache bug was reproduced and corrected with automated raster-output comparisons. Visual confirmation of the complete reported appearance on macOS and Windows remains outstanding; this release does not claim every possible font-shaping or baseline issue is resolved.

Linux x86_64, macOS Apple Silicon, and Windows x86_64 bundles use the same immutable stable tag on `main`. Payloads include SHA-256 sidecars and exact source/version metadata. Private `.neoism` files and ignored local build artifacts are excluded.
