# Neoism v0.7.159-nightly.20261117.1

This prerelease previews the native Rune Markdown editor and the latest Notes workflows. Stable downloads remain on the current stable release.

## Markdown and Notes

- Native Markdown live preview with source editing, headings, inline formatting, task checkboxes, tables, code blocks, images, links, page decorations, and block dragging.
- Markdown collaboration and presence integrated with the shared document, native input, and editor navigation.
- Notes sidebar shortcuts: `a` creates a note, `e` renames, and `d` opens delete confirmation. Nested paths and trailing-slash folder creation are supported.
- File and folder renames preserve live editor buffers, unsaved text, undo history, caret, and collaboration identity. Stale saves cannot recreate the old filename.
- External changes highlight edited Markdown and code rows without taking keyboard focus or moving the reader to the change.

## Validation

Platform release jobs build, test, and package Linux x86_64, macOS Apple Silicon, and Windows x86_64 independently. Local checks and publication status are reported separately; these notes do not imply manual testing on all platforms.
