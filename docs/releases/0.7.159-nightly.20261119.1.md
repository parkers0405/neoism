# Neoism v0.7.159-nightly.20261119.1

This nightly includes the current Rune frontend and MCP updates on the Markdown integration branch. It is a prerelease and does not replace the latest stable release.

## Changes

- Native Mermaid previews in Markdown notes and agent replies, with source access, copying, larger previews, bounded background rendering, and editable source on errors.
- Native Markdown spelling feedback, corrections, ignored words and custom dictionary support without attaching Markdown documents to language servers.
- Markdown section-fragment links, including asynchronous navigation, encoded headings and repeated-heading suffixes.
- Editor soft-wrap, caret, presence and diagnostic layout updates, plus sidebar and terminal presentation improvements.
- MCP browser authorization now completes the server connection and refreshes the tool catalog; connection dialogs expose completion, failure and dismissal states.
- Updated verification fixtures, examples and benchmark documentation. Disposable benchmark clones and generated local build files are not part of the release source.

## Validation

Local tests and platform release checks are reported separately. Each platform builds, tests and packages independently before publishing; this is not a claim of manual GUI validation on every operating system.
