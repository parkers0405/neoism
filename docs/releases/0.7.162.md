# Neoism v0.7.162

This stable release redesigns the Agent sidebar, Settings, the model picker and the composer, adds projects from a new or cloned repository, and adds Copy, Fork and Reply under answers, on Linux, macOS, and Windows.

## Agent sidebar

- The sidebar opens with a search field and three buttons: filter by project, add a project, and new chat. Search matches a conversation's title or project; `/` focuses it.
- Conversations are cards: the project and age on top, the title below, and the framework's mark. Pinned conversations lead the list and carry a pin.
- Each card shows what its conversation is doing in place of the age: running, background work, compacting, waiting on you, or finished since you last looked. Each has its own motion and colour.
- On `~`, or with the filter on **All projects**, conversations group under their project folders, five to a project with **Load more**. More projects load as you scroll. Choosing **All projects** no longer moves the workspace to your home directory.
- `/sessions` lists the same conversations by the same rules.

## Add a project

- The add-project button offers **New project**, **Local folder**, **Git URL** and **GitHub repository**. The workspace daemon creates the folder and repository, or clones it, and the workspace opens in it. The location can be changed before it starts.
- The daemon refuses a target folder that is not empty, relative paths, and addresses that are not ordinary Git addresses. Clones run without a terminal, so a private repository needs a credential helper or SSH agent.

## Answers and the composer

- Under each finished answer, on hover: **Copy**, **Fork** and **Reply**. Fork opens a new conversation holding everything up to that answer. Reply quotes the answer in your next message, shown as an inset chip.
- The composer shows the model beside the send button and the paperclip on the left. The model opens one card: providers down the left with a Favourites tab and a button to connect another, the provider's models with a star to favourite them, and the reasoning levels on the right. Search covers every provider's models.
- Reasoning levels follow the model: Claude's extended thinking from off to max, Gemini's low to high, OpenAI's as before. Grok models that do not accept a reasoning setting are no longer sent one.
- Clicking the token count under the composer opens the context window meter with the last turn's breakdown and a Compact button.
- Menus above the composer can open out into a window-centred modal, close with a red button, step back a level with Escape, scroll under a finger on touch screens, and keep their arrow keys after a click.
- A model catalog that is still being prepared is asked for again automatically instead of showing an error until the picker is reopened.

## Settings and look

- Settings opens from a gear at the foot of the rail and is organised into General, Appearance, Themes, Backgrounds, Keybindings, then Code, Agents and System groups, with search in its sidebar. Markdown settings have their own page.
- Themes and Backgrounds are galleries with a preview of the window. Backgrounds adds opacity, blur and fit, and the sidebars stay solid over a background picture.
- Sidebars, Settings, the palette, finder and menus use the proportional interface font. The title bar matches the window background.
- Cmd+W no longer closes a tab by default; bind it under Keybindings if you want it.

## Agent server

- Sessions can be prompted only when idle (`POST /v2/sessions/{id}/prompt-if-idle`), answering 412 otherwise.
- A fork can be a conversation of its own (`detached`) and can be cut at a transcript part as well as a message.

## Validation and downloads

Linux x86_64, macOS Apple Silicon, and Windows x86_64 build, test, and package independently from the same immutable stable tag. The daemon image uses the same tagged source. Local checks, publication and checksum verification are reported separately; this is not a claim of manual GUI testing on every platform. The interface changes were checked from headless renders and automated tests rather than a full manual pass. The macOS bundle is signed with a Developer ID and publishes only if Apple notarizes it.
