# Neoism v0.7.155

Release preparation date: 2026-11-14 (host local date).

## Linux release validation and input/layout regressions

- Validation-only `Release Neoism` workflow dispatch mode (`validate_only`) for full application `cargo test --locked --release`, using the `scripts/build-rune-release.py --test-app-only` branch without release creation, desktop asset packaging, or uploads.
- Installs Mesa's software Vulkan driver on Linux CI so the real offscreen scroll-image integration test has an adapter; the test remains enabled.
- Uses the platform's Select All modifiers in compact-query tests and sub-pixel tolerances for floating-point activity geometry comparisons.
- Reserves flame clearance before an optimistic send is acknowledged, avoiding the approximately 1.2-pixel message-bubble shift without weakening the movement assertion. Covers flame on/off, multiple font sizes, and reveal completion.
- Releases pending touch taps at the original press point, so sub-threshold finger jitter does not become a mouse drag, text selection, or editor Visual mode. Actual touch drags retain their endpoint; adds near-threshold jitter coverage across code, Markdown, prose, and fenced code.
