# Neoism v0.7.149-nightly.20261110.4

The fourth Rune nightly includes the changes in nightly `.3` and fixes a completed background sub-agent appearing to run forever.

## Changes

- A stopped sub-agent stays stopped when the parent's completed turn refreshes its task cards. Only a newer family snapshot can mark it running again.
- A task card whose sub-agent has stopped shows completed. The same reconciliation applies when opening an older conversation.

## Validation

Two regression tests replay the traced completion and parent-refresh event order. The Rune app's 304 tests passed for the fix. Live confirmation of the reported sub-agent behavior remains pending.
