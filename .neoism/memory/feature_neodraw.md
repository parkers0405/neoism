Building a `.neodraw` Excalidraw/tldraw-style hand-drawn vector editor. Started 2026-06-04.

**Decisions (locked):** homegrown JSON scene format (serde); lives in the **shared** crate at `neoism-frontend/shared/src/editor/neodraw/` (so web+desktop both get it, per [[feedback_desktop_vs_web_paths]]); full interactive editor (not just render); markdown ` ```draw ` embed (phase 8) **references** a `.neodraw` file path (not inline scene) so the drawing stays always-editable like Excalidraw. Module is named `neodraw` because `render/draw.rs` already owns "draw".

**Renderer = sugarloaf**, mirroring `editor/markdown/render/mermaid.rs` (fenced-block-intercept pattern in `render/mod.rs`). Sugarloaf has `line/arc/polygon/triangle/rect/rounded_rect/text` — the hand-drawn wobble is a deterministic seed-based jitter pass (seed stored per-shape in `Style.seed` so strokes don't shimmer across frames).

**App wiring pattern:** `Chrome` holds typed editor fields (e.g. `markdown_pane: Option<MarkdownPane>` at `chrome.rs:328`), fed by the desktop bridge via `set_markdown_content` and dispatched by extension (`is_markdown_path`, `activate_markdown_path` across `desktop/src/screen/bridges/*`). A `.neodraw` editor mirrors this: a `draw_pane: Option<DrawPane>` field + `set_draw_content` + extension dispatch + a draw branch in `Chrome::draw`.

**8-phase plan:** 1 model+serde ✓ · 2 renderer+rough ✓ · 3 select/move/resize ✓ · 4 creation tools ✓ · 5 pen+text · 6 toolbar/palette UI · 7 undo/copy/delete/rotate/save · 8 markdown embed. Phases 1-4 done as pure+tested logic in shared crate (30 unit tests).

**Desktop open+render slice DONE** (both crates compile): `.neodraw` opens from the file tree and renders the hand-drawn scene. Wired by mirroring markdown's per-surface `Context` pattern — desktop uses a `context_manager` of `Context` objects with one `Option<Pane>` per surface (NOT chrome.rs's `markdown_pane`, that's the wasm path). Touched: `context/tab.rs` (`Context.draw` field + Drop guard), `context/factories.rs` (`create_draw_context`), `context/manager.rs` (`add_stacked_draw`, `draw_node_by_path`, 2 more Context literals), `screen/bridges/draw.rs` (new: `open_path_in_draw`/`activate_draw_path`/`render_draw_panels`/`save_current_draw`), `file_tree.rs` dispatch, `render/mod.rs` render call, `save_current_document` branch, `editor/neodraw.rs` shim. Reused `buffer_tabs.open_markdown` for tab registration (content type driven by Context fields). Shared `render_pane()` draws canvas bg + scene + draft + selection overlay. Sample at repo-root `Ambiguity.neodraw`.

**FEATURE COMPLETE (both crates compile, 44 shared unit tests).** All 8 phases done: model, rough renderer, select/move/resize, create (rect/ellipse/line/arrow/pen), text editing, toolbar (tools+colour+size at bottom), undo/redo + copy/paste/duplicate/delete, save (Ctrl+S), and the markdown ` ```draw ` embed (body = relative path to a .neodraw, rendered read-only fitted into a block, in `render/draw_embed.rs`).

Input wired in `screen/bridges/draw.rs`: mouse press/drag/release arms in `app/window_event/mouse.rs`, key interception in `screen/selection.rs` before the markdown gate. Shared interactivity lives in `neodraw/{input,text,history,toolbar,edit,create}.rs` as pure tested methods (`begin/drag/end_pointer`, `set_tool`, `dispatch`-style). Keys: V/H/P/R/O/A/L/T tools, Esc, Del, Ctrl+Z/Y/C/V/D/A.
