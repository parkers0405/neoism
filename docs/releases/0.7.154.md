# Neoism v0.7.154

Released 2026-11-14.

This stable release includes the current workspace changes, with fixes for Linux test compilation, macOS tool discovery, and streamed Agent activity spacing.

## Changes

- Fixes Linux keyboard-test compilation by gating the assertion that calls the macOS-only `ui::chrome::glass_cursor_allowed` function with `#[cfg(target_os = "macos")]`. The keyboard navigation test remains enabled on all platforms.
- Improves tool discovery for Finder-launched macOS processes by recovering PATH from a bounded login-shell invocation before threads start, with a tool-directory fallback. Standalone startup performs this recovery before starting Tokio.
- Adds extra top padding to Agent activity only while streaming with wordmark flames active. Normal reduced-motion behavior remains respected.

## Linux release recovery

The v0.7.153 Linux application binary compiled successfully, but test compilation failed with E0425 at `rune/app/src/keys.rs:473` because the test unconditionally called a macOS-only function. The failure was recorded in GitHub Actions run [43648967865, job 132612993483](https://github.com/parkers0405/neoism/actions/runs/43648967865/job/132612993483). This release includes the platform guard without disabling the cross-platform keyboard navigation test.

## Verification

Focused checks on macOS passed in `rune/app`: `./build.sh test --locked keys::tests` (8 passed) and `./build.sh test --locked agent::activity::tests` (13 passed). These commands compiled the application test targets. The previous Linux failure was diagnosed directly from its CI compiler error and corrected with a compile-time platform guard; a local Linux runner is not available, so the new GitHub Linux job provides Linux validation. No full-suite run or exhaustive GUI, provider, tool-discovery, or cross-platform validation is claimed.

The daemon library's shell-environment checks also passed on macOS (3 passed), covering PATH precedence, language-server child-runtime lookup, noisy login profiles, and bounded termination of hung profiles. The daemon binary and library test targets compiled using Rust 1.99.1.

## Release packages

The existing independent per-platform publishing workflow is unchanged. Linux x86-64, macOS ARM64, and Windows x86-64 build from the new stable tag. Each platform uploads its downloads and publishes the shared release as soon as its own job succeeds; another platform's failure does not block it. Existing v0.7.153 macOS and Windows downloads remain intact. The daemon container image uses its separate workflow.

Existing GitHub platform build, test, and packaging steps remain enabled. Existing database backup and downgrade cautions remain applicable. Ignored local build outputs and private workspace state are excluded.
