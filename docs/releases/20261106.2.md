# Neoism v0.7.143-nightly.20261106.2

This nightly includes the current source snapshot across the native desktop, agent services, workspace daemon, shared UI, packaging, and developer utilities. Stable remains on v0.7.142.

## Changes

- Native agent orchestration and ACP lifecycle, event projection, child streaming, session recovery, model catalogs, and options handling, with regression fixtures and runtime contract documentation.
- Browser and OpenAI authentication flow improvements, daemon credential handling, shell execution, and local process lifecycle fixes.
- Native and shared agent timeline, shell blocks, selection pickers, provider artwork, titlebar, activity rail, sidebar, and keyboard/navigation improvements.
- Workspace isolation and startup handling, Windows GUI executable and freshly built service provenance gates, and the updated GPUI platform patch.
- Offline history-cleaning and display-only text-filter utilities, with safety documentation and tests. No private histories, credentials, local build artifacts, or `.neoism` memory changes are included in this snapshot.

## Build provenance

The immutable release tag identifies the initial source snapshot. Platform bundles include `build-info.json` with their exact source commit, version, platform, and architecture; Windows bundles also record service hashes. Any necessary platform-specific retry uses an exact source commit without moving the tag or rebuilding successful platforms. Published payloads have SHA-256 sidecars.

## CI follow-up

The initial platform gates caught recording-renderer fixtures that still assumed open-by-default sidebars/details or the previous header geometry, plus an outdated optional capture-overlay base hash. The fixtures now explicitly arrange their required panels and use native cursor geometry without removing their behavioral assertions. The full local frontend regression suite passes against the cached development core.

Windows additionally exposed Bun 1.3.13 emitting a console-subsystem PE despite the requested `hideConsole` option. Packaging now explicitly sets the actual loader subsystem to GUI, preserves the rest of the executable and embedded payload byte-for-byte, and verifies the persisted image before publication. Both rejection tests and payload-preservation tests cover this path; Windows CI retains its launcher, installer, updater, and fresh-service provenance gates.
