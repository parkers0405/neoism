# Neoism v0.7.145

This stable update includes the work prepared for the canceled, unpublished v0.7.144 release, plus the sidebar mouse-focus fix. The original v0.7.144 tag is preserved and its empty draft is superseded rather than retagged.

## Changes

- Clicking the activity rail to close or reopen a sidebar preserves editor/content keyboard focus and avoids leaving a stale sidebar cursor. Keyboard shortcuts and Alt-arrow navigation retain their explicit focus-transfer behavior.
- Enable TCP_NODELAY for direct workspace-daemon and agent-server connections to keep small interactive and streamed updates responsive.
- Batch terminal output bursts on presentation frames with a timer fallback for hidden windows. Preserve immediate first echo, bounded buffering, replay offsets, response boundaries, and flush ordering before input or directory changes; isolated echo does not register an empty presentation callback.
- Avoid document repaints for unchanged peer heartbeats or unrelated buffers, and preserve editor recovery across presence-only updates. Unchanged local cursors no longer schedule redundant presence work.
- Offer authorization-only MCP actions when credentials or client registration are required.
- Route exact system-scoped MCP browser OAuth callbacks through the existing one-time-state validator without requiring a browser bearer token. Preserve callback HTML while retaining authentication and scope restrictions for other routes and methods.
- Include regression coverage for mouse/keyboard focus, terminal batching/replay, presence repaint/recovery, and MCP callback authentication. Proxy fixtures match the current health and explicitly master-only system MCP capabilities.

## Downloads and provenance

Linux x86_64, macOS Apple Silicon, and Windows x86_64 bundles are built from the same immutable stable tag on `main`. macOS includes a DMG and Windows includes an MSI. Every payload has a SHA-256 sidecar, and each platform includes exact source/version metadata. Unchanged shared documentation remains pinned to its published revision.

Private `.neoism` configuration and memory, local histories, and ignored build artifacts are excluded from the source release.
