# Neoism v0.7.169

This release adds a Workflows panel, improves external-agent connections, and makes it easier to open and preview local files.

## Agent and workflows

- Open **Workflows** from the command palette (`Alt+P`) on a local Unix daemon to browse workspace prompt workflows, inspect their Markdown source, and see recent runs. Activate, pause, or run eligible workflows after reviewing the confirmation.
- See external-agent connection status in the model picker and launch sign-in when a harness needs it.

## Files and appearance

- Click an image in the file tree to open a read-only preview that fits its pane. Reopening the same image selects its existing tab.
- On macOS, open supported local files from Finder. The `presence.avatar-palette` setting also offers an optional `obsidian-gold` palette for your own presence orb.

## Validation and downloads

Linux x86_64, macOS Apple Silicon, and Windows x86_64 build, test, and package independently from the same immutable stable tag. The daemon image uses the same tagged source. Local checks, publication and checksum verification are reported separately; this is not a claim of manual GUI testing on every platform. The macOS bundle is signed with a Developer ID and publishes only if Apple notarizes it.
