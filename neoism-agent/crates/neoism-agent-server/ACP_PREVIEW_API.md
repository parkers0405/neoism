# ACP pre-chat options API

`GET /v2/external/options/preview?provider=opencode|claude|codex&directory=<workspace>` (directory optional, following the usual query/header directory resolution) returns the same JSON shape as `GET /v2/sessions/{id}/external/options`:

```json
{"provider":"opencode","configOptions":[],"modeFallback":false,"selectedOptions":{},"externalSessionId":null,"availableCommands":[]}
```

`configOptions` is the complete provider-ordered ACP `session/new` snapshot (including a synthesized `mode` select only for legacy modes). Provider notifications may update it. No model IDs are invented. A cold preview initializes the selected provider, creates an ephemeral ACP session, does not prompt, does not create or update a Neoism store session, and terminates the adapter after the request. The opaque ephemeral session ID is intentionally `null` because it cannot be reused. Missing adapter/auth/setup errors on a cold miss produce HTTP 400. Unknown providers produce HTTP 400; hosted, tenant and workspace-identity claims produce HTTP 403; directory prefixes are checked against the canonical directory before any cache read or adapter launch.

`POST /v2/external/options/preview?provider=opencode|claude|codex&directory=<workspace>` accepts `{"selectedOptions":{"model":"provider-advertised-id"}}` and returns the same response shape. On a cold miss it runs the selected values against an ephemeral ACP session in provider/dependency order, so `configOptions` includes selectors that become available only after a model change (for example OpenCode effort). `selectedOptions` contains only provider-confirmed requested values. Missing/unadvertised/unconfirmed selectors fail with HTTP 400 without creating a Neoism root. POST uses exactly the same local-operator and canonical-directory checks as GET.

## Preview cache

GET and POST share a server-only, versioned (`version: 1`) JSON snapshot cache at the Neoism cache root (`NEOISM_AGENT_CACHE_DIR` if set, else `$XDG_CACHE_HOME/neoism`, else `~/.cache/neoism`) in `acp-options-v1/<sha256-key>.json`, **not** `models.json`. Each record contains `version`, `key`, Unix-seconds `saved_at`, and `response` (`provider`, sanitized `configOptions`, `modeFallback`, confirmed `selectedOptions`, `externalSessionId: null`, sanitized `availableCommands`). Adapter extension fields and environment values are not stored; only public selector/command fields are retained. Corrupt, oversized (>1 MiB), wrong-version, mismatched, or invalid/unconfirmed snapshots are ignored. Files are written via a unique temporary file and atomic rename. Cache failures do not prevent live previews.

The key hashes schema version, provider, canonical CWD, exact selectedOptions map (including empty GET), resolved adapter command and args (including pinned package version), executable size/mtime, and adapter environment configuration. The environment is hashed, never written. Changing any of these contexts invalidates the entry; TTL is 10 minutes. A fresh hit returns without launching ACP, including after server restart. A stale hit returns last-good immediately with `catalogStale: true` and schedules one background refresh per key. Refresh failures retain the snapshot and back off 60 seconds; cold misses wait on a same-key flight and run at most one handshake. Other keys are independent. Local operator, caller claims, and canonical directory scope checks precede cache access. Neither cached snapshots nor draft validation authorize a root or bypass the fresh provider validation/replay on the first prompt. No ACP session IDs or credentials are persisted.

`POST /v2/sessions?directory=<workspace>` accepts `{"externalProvider":"opencode","externalOptions":{"model":"provider-model-id","mode":"code"}}`. `externalOptions` is an optional map of ACP config option ID to advertised select value. A nonempty draft is checked against a fresh provider session, including conditional selectors, before writing a Neoism root. Unsupported, missing, non-select, unconfirmed, or malformed values fail (400) without a Neoism session. Choices are stored as `extra.externalAgent.selectedOptions` with `optionsValid:false` and replayed against a new ACP process on the first options GET or prompt. Provider session IDs from validation are never attached to the root. Normal subsequent session option GET/POST and prompt replay remain unchanged. External options cannot be supplied to non-ACP sessions or imported roots.
