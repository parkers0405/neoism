**Mash Up Packs** (user-named, like Minecraft Xbox mash-up packs): bundles skinning the whole app as one look. Core shipped 2026-07-11 (uncommitted that day).

**Architecture (verify files still exist):**
- Runtime theme registry: `shared/src/primitives/ide_theme.rs` — `IdeThemeName::Custom(&'static str)` (leaked-interned to keep Copy), `replace_custom_ide_themes` (full-sync per disk scan, builtins unshadowable, re-intern reuses leaks), `all_ide_theme_names`, `IdeTheme::from_overrides(extends, pairs)` (lenient hex parse + warnings), `lua_palette_pairs` (lua key mapping: line=surface, surface=hover).
- Disk formats (backend `config/mashup.rs`): **JSON since 2026-07-14** — `ide-themes/*.json` + `packs/<id>/{pack.json,theme.json}` (JSONC dialect via config's `parse_config_content`, extension-dispatched; legacy .toml still loads via `existing_variant(dir, stem)` json>jsonc>toml). Seeds + Parker's installed packs converted to JSON. `MashupPack {theme, shader_overlay (builtin:* or pack-relative), filters, font_family, look: LookConfig}`; `LookConfig {scrollbar, markdown(checkbox/font-family), icons: map}` parsed from pack.json TOP-LEVEL `"scrollbar"/"markdown"/"icons"` keys AND from config.json `"look"` (Config.look field) — merge via `merged_under` (config wins field-by-field).
- Look runtime cell: `shared/src/primitives/look.rs` — `ACTIVE_LOOK` (Arc), `scrollbar_style()` (Option-per-field with `*_or(site_default)` helpers so empty style = pixel-identical), `markdown_checkbox_look()` (Modern|Retro95), `markdown_font_family()`, `icon_override(key)`, `intern_glyph`. Desktop pump: `desktop/src/mashup.rs` (`sync_custom_ide_themes`, `publish_active_look`, `seed_example_packs` — seeds phosphor + retro-95 via include_str! only when packs/ dir absent).
- Apply: `apply_mashup_pack` in `chrome_geom.rs` (theme→apply_unified_theme which persists `[neoism] theme`; shader always set to pack value incl. None; filters only-if-nonempty; font via `write_fonts_family` → watcher rebuilds FontLibrary; persists `[neoism] mashup-pack`; publishes look immediately with fresh Config::load). Startup (`screen/mod.rs` Screen::new): seed→sync→publish→pack shader/filters re-applied; THEME comes from `[neoism] theme` only (individual override wins on restart by design).
- Custom-theme nvim: `vim_apply_custom_theme_command` (backend commands.rs) → `rio.theme.apply_custom(name, {palette})` added to theme.lua.
- Picker: palette "Mash Up Packs" → `mashup_packs_modal_spec` (`ModalAction::ApplyMashupPack{id:Option}`); theme picker appends registry customs; pickers re-sync from disk on open.
- Welcome doc: `Configuration/Mash Up Packs.md` (seeded new vaults only — marker-gated).
