# Neoism v0.7.149-nightly.20261111.4

This Rune nightly follows `20261111.3`.

## Changes

- The workspace daemon no longer exits when its Agent server cannot start. Another owner holding the Agent lock without answering yet, or a port that could not be bound, used to end daemon startup, taking files, notes and terminals down with the chats. The Agent is now retried for 20 seconds before the daemon starts serving, then every 2 seconds in the background for as long as it takes. Once it runs, the supervisor that was already there keeps health-checking and restarting it.
- The app replaces a daemon it started that is still running but has answered nothing for the whole start grace (two minutes, four on Windows). While a stuck daemon lives it holds the ownership lock, and every daemon started beside it exits at once. Only a daemon this app process started is ever stopped.
- The Notes header has two buttons: a new note (`Untitled.md`) and a new folder (`New Folder`), made beside the selection and numbered when the name is taken. A new note opens for writing.
- A notes vault no longer lists its `.json` files (`project.json`, notebook metadata).

## Validation

The Rune app's 349 tests pass at this commit. The daemon was built at this commit and a window was cold-started against it in an isolated home that uses the macOS file layout: connected, workspace open and shell up in 2.4 s. The daemon's Agent retry and the replacement of a stuck daemon were not triggered live: an attempt to hold the Agent lock from outside did not block the daemon, so neither path has been seen working, and the restart decision has unit coverage only. The empty-window report from Windows and macOS that prompted this has still not been reproduced. The Notes buttons and the hidden JSON were seen in a real window; creating a note is covered by its unit test and was not clicked against a real vault. A window that connected before a late Agent came up on a non-default port keeps the old address until it reconnects. The macOS and Windows builds are gated by CI only.
