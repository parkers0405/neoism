Follow-up user-reported Hyprland keyboard failures: Unknown key Super_L, Unknown modifier super, Invalid XKB keymap while pointer/capture worked. Only computer_use.rs, computer_use/platform.rs, computer_use/shortcuts.rs and docs/computer-use.md changed; independent agent owned MCP picker UI.
Reader bug: shortcuts::linux::Probe used offset-relative File::read_to_string/take on SCM_RIGHTS keymap FD. Shared file-description offset can be EOF (Enigo0.6.1 Keymap2::format_file_size writes keymap to temp FD and leaves cursor EOF). Empty read becomes Invalid XKB keymap despite valid bytes. Replaced with bounded FileExt::read_exact_at(offset0) using advertised size, leaving shared cursor unchanged. Strip trailing NULs; reject empty/embedded-NUL, truncated, oversized, nonUTF8 or genuinely invalid maps; no layout fallback. Probe::record_keymap keeps latest event: valid replacement clears prior error, invalid replacement discards stale map. Real libxkbcommon regressions cover EOF/intermediate offsets, dup-shared-cursor preservation, NUL/noNUL, malformed/truncated maps and replacement recovery.
Alias normalization now case-insensitive/trimmed. modifier aliases control/ctrl/Control_L; alt/option/Alt_L; shift/Shift_L; meta/super/Super_L/win/windows/logo/cmd/command. Same modifier aliases accepted as standalone key taps. Return, Esc, BS, Del, Spacebar, ArrowLeft/Right/Up/Down, PageUp/PgUp/Prior, PageDown/PgDn/Next accepted. Duplicate aliases rejected after Key normalization. MCP schema/help explicitly advertise aliases; removed restrictive modifier enum so uppercase aliases are not schema-rejected.
Native Unicode text kept separate from shortcut resolver. Linux type_character accepts impl Keyboard for safe unit tests; verify Google search case/punctuation/lambda/emoji/newline/tab produce paired press/release and release attempted after failed press. Independently audited EXACT Enigo0.6.1 parse_keymap.rs in /tmp/neoism-enigo-keymap-audit (test-only temporary harness, no source vendoring): generated initial + remapped uppercase/punctuation/Unicode keymaps parse with real XKB and produce expected symbols. No Enigo object created, no input emitted in audit.
