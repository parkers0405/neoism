# Safe archive manifest

Repair `manifest.build_manifest(entries, case_sensitive=True)` in this private synthetic stdlib repository. No filesystem access is required: all paths are interpreted lexically, independent of host OS.

Entries is a list of exact objects: `{path: string, type: "dir"}` or `{path: string, type: "file", size: integer >= 0}`. Bool is not a valid size. Other types, missing/extra keys, and non-string paths are invalid_entry. Convert backslashes to slashes. Reject paths beginning with slash, beginning with an ASCII letter followed by colon, containing NUL, or containing any `..` segment (even if it could be resolved safely). Remove empty and `.` segments. Reject a resulting empty path. Files may not end in a slash/backslash; directories may. All these path rejections are unsafe_path. Preserve all other spelling, whitespace, and Unicode; do not URL-decode.

Normalize every explicit entry and synthesize each missing ancestor as a dir. File ancestors are forbidden. Explicit dirs may replace previously synthesized dirs, but two explicit entries at the same normalized path collide, including two directories. A file replacing a synthesized dir is path_conflict. For each input in order, check the normalized leaf against prior entries first (collision if explicit; path_conflict if replacing an implicit dir with file), then ancestors from root outward (file ancestor is path_conflict). On a case-insensitive manifest, path identity uses Python str.casefold(); ancestor paths and leaves share this identity space. Keep the spelling from the first occurrence of each full normalized path, including implicit ancestors; do not rewrite descendant spellings.

Return `{entries: [...], total_bytes: integer, error: null}`. Output objects have exactly the input fields with normalized paths (implicit dirs have path/type only); sort by stored path using Python string ordering, not identity keys. total_bytes sums files once. Errors return empty entries, total_bytes 0 and `{code: CODE, index: input_index}`; the whole operation is atomic. Non-bool case_sensitive yields invalid_options/index null before any other checks. Non-list entries yields invalid_entries/index null. Otherwise first sequential error wins, shape before path before collision/ancestor checks. Never mutate or alias input containers. Run `python -m unittest discover -v` in workspace.
