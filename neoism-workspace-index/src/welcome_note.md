# Welcome to Neoism

Neoism brings your terminal, editor, AI agent, and Markdown notes into one workspace. Open a project, run a command, or ask the agent to help with your code.

## Start here

- [ ] **Open your first project**
  - Press `Ctrl+Shift+W` to create a workspace, or use the `+` in the workspace tab strip.
  - Press `Alt+P` and choose **New Workspace** if you prefer the command palette.
- [ ] **Run a command**
  - Press `Alt+T` to open a terminal. Try `pwd`, then press `Enter`.
  - Use `Tab` to preview completions and `Up` to browse command history.
- [ ] **Open a file**
  - Press `Alt+E` to open the file explorer and select a file, or `Alt+S` to search for one.
  - Make a change and press `Ctrl+S` to save it.
- [ ] **Start an agent conversation**
  - Press `Alt+A` to open the agent, choose a configured provider and model, and describe your task.
  - Press `Alt+C` to open your conversation history.

Press `Alt+N` to open Notes and make this vault your own. This welcome is yours to edit, check off, or delete; `Alt+P` opens the command palette whenever you need another action.

## Move focus without the mouse

Use `Alt+Left` / `Alt+Right` to move focus between content and visible side panels or neighboring panes. `Alt+Up` moves from content to the buffer tab strip, then up again to the workspace strip; `Alt+Down` moves back toward content. On macOS, `Alt` is `Option`.

## Documentation

Open `Alt+P` → **Open Documentation**, or run `neoism docs` in a terminal, to open the local documentation browser. It contains the full handbook and the **Scalar API reference**; choose the handbook for workflows and shortcuts, or the API docs for endpoints and request examples. Keep the standalone command running while you read; `Ctrl+C` stops its server. Documentation stays in the browser rather than filling your Notes vault.

The public handbook and Scalar API reference are also available at <https://neoism.ai/api/docs/>. If you used an older Neoism version, your previous handbook copies in Notes are preserved; you can keep or remove them yourself.
