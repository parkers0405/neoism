2026-08-18 six-agent audit of desktop (golden standard) vs shared (`neoism-ui`) vs wasm/web host, prepping web for Capacitor/iOS. Full report artifact: https://claude.ai/code/artifact/1c8c30f9-6078-4212-8de9-5becfb45b41d

**Root cause:** desktop bypasses `neoism_ui::Chrome` (own panel roster, host/mod.rs:74-243); web consumes ONLY `Chrome<()>` — Chrome is web's ceiling. Chrome hosts one editor pane (`markdown_pane`, chrome.rs:287); desktop hosts seven. Biggest gap class = finished shared code with zero consumers, not missing ports.

**Tier 0 bugs:** composer Ctrl+W/U/K/A/E leak to raw PTY (TerminalPanel.ts:7046); agent `apply_history` clobbers streaming/optimistic state (dead helpers state/ingest.rs); `question` tool hard-stops web runs (no protocol envelopes); notebook execution.rs `Command` ungated on wasm; diagnostics popup fed but never painted (no render call in Chrome::draw); 8×16 fake cell metrics (chrome_shim_more.rs:36); TS drop-zone geometry duplicates shared consts; 5 shared files never declared in lib.rs (hint_policy, hint_state, terminal_scroll_state, scheduler, config_watcher_policy).

**Keystone fixes:** multi-pane Chrome (add code/notebook/draw panes → unlocks complete shared CodePane+painter, NotebookPane render, neodraw); UniversalModal wiring (101 desktop refs, 0 web — window.prompt today); PaneGrid (complete+tested, ZERO consumers repo-wide); terminal selection/copy + scrollback (machinery compiled, uncalled); git write protocol (GitClientMessage only Status|Diff|Log; staged:false hardcoded); slash-command table drift (delete execute_slash_text → plan_slash_command); themes 4→~100 (all_ide_theme_names already in wasm binary); LSP lift (3,869-line desktop bridge, protocol already finished both sides in neoism-protocol/src/editor.rs:90-158); markdown dispatch 900 lines vs 15 keys; wasm terminal renderer 27 releases behind terminal_grid_emit; key_policy/mouse_policy unused → TUIs broken on web.

**iOS-critical:** TS reimplements Rust policy modules (imePolicy/touchPolicy/RemotePresenceStore/key encoder) — route through Rust before a third copy; ServiceRegistry.ts declares 4 of ~12 services.

**Dead code:** pairings_settings, remote_carets panel, widgets::Overlay<T>, ~20 uncalled wasm bridge methods.

**N/A for web:** cross-window drag/detach, discord, ssh -L tunnels, reMarkable, ipc/embedded-daemon.
