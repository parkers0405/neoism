# Neoism v0.7.165

This stable release makes the Agent pickers easier to use and keeps the activity line steady during tool completions.

## Agent

- Scroll the model picker with small trackpad or touchscreen gestures, whether it is above the composer or expanded into a modal. The list follows your gesture instead of waiting for a whole row of movement.
- Type `$` in the composer to find a skill, use Up or Down to choose it, then press Enter or Tab to insert it. Escape dismisses the menu. `/skills` still opens its own search field.
- When a step succeeds inside a closed Working group, only the arrow beside Working hops; Crafting does not restart its animation. With the group open, the tool icon still hops.

## Validation and downloads

Linux x86_64, macOS Apple Silicon, and Windows x86_64 build, test, and package independently from the same immutable stable tag. The daemon image uses the same tagged source. Local checks, publication and checksum verification are reported separately; this is not a claim of manual GUI testing on every platform. The macOS bundle is signed with a Developer ID and publishes only if Apple notarizes it.
