# Neoism v0.7.149

The full stable release of the native Rune frontend, promoted from the completed `v0.7.149-nightly.20261111.10` source. Linux x86-64, macOS ARM64 and Windows x86-64 packages are rebuilt with version `0.7.149`, alongside the workspace daemon and agent services. Successful platform packages publish as they finish, as in the preceding release workflow.

Includes the complete Rune branch: editor, terminal tabs and splits, agent conversations and tool cards, sub-agent families, image attachments, Notes, settings, Git changes and file-tree decorations, collaboration, workspace/server selection, queued prompts, reconnect/sleep recovery, and Windows workspace-directory fixes. Performance changes include virtualized transcripts, avoided ignored-event redraws, lightweight offscreen tool grouping, bounded round-robin event processing, and live activity revision fences.

The previous nightly passed Linux, macOS, Windows and daemon production builds. Local verification recorded 395 Rune tests passing and one intermittent reconnect timeout, with that test passing in isolation, plus 12 daemon hydration tests passing and optional profiling compilation passing. Stable packaging and signatures remain subject to this release's production checks. This does not claim complete UI parity or exhaustive live cross-platform validation. Existing database backup and downgrade cautions continue to apply.
