# Neoism v0.7.156

Release preparation date: 2026-11-16 (host local date).

## Cursor boundaries, touch controls, and editor consistency

- Clips the cursor and native glass lens to the viewport even when focus changes through the file tree, Settings, or menus.
- Makes tab and workspace close targets available to touch before hover. Dragging or cancelling a touch does not close the tab or workspace.
- Refreshes cached Files and Notes directory listings when scoped watch `Changed` events arrive from external writers, preserving expanded directories without refreshing unrelated roots.
- Treats the available LSP state as initializing, rather than incorrectly showing the language server as missing.
- Uses shaped fractional width for `Type.advance` and includes the font epoch and code font family in measurement memoization, preventing editor caret and hit-testing drift on long lines after font changes.
- Uses Option for default application panel shortcuts on macOS and Alt on other platforms, preserving Command-based editing chords.
