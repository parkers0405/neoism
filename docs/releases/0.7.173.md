# Neoism v0.7.173

**Phone pairing on Windows and Linux:** Connect your desktop and iPhone to the same Tailscale network, select **Pair a phone** in Neoism, and scan the short-lived QR code. This is the same flow already available on macOS. If pairing setup fails, the desktop now shows what to check.

This desktop release targets Linux x86_64, macOS Apple Silicon, and Windows x86_64. The iOS app is distributed separately.
