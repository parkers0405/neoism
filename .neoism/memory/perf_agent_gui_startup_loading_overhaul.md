Implemented 2026-08-?? (current session; no commit/push): Agent GUI startup loading overhaul. Root causes were unbounded full-table session JSON decode, swallowed errors -> false empty, synchronous stale models.dev refresh, repeated config discovery, sync desktop picker HTTP, and repeated migrations. New agent-server `session_list_index` sidecar is created constant-time and dual-written transactionally from insert/update/update-with-event/delete. `/v2/sessions?roots=true` now queries sidecar with SQL directory/path/search/start filters, clamped 1..200 limit, deterministic `(updated, session_id)` keyset cursor and real `PageCursor.next`. Existing ~7.87GB sessions table is never synchronously rewritten/scanned at startup; resumable newest-first backfill runs after serve starts, in 16-row batches, JSON decoding via spawn_blocking, 100ms duty-cycle sleeps, persisted cursor, retries, and conflict guard so live writes win. While backfill has no matching projected rows endpoint returns retryable 503 rather than false empty. Added schema/data migration ledgers and ledgered prior execution-activity migration to stop repeated ALTER/UPDATE/INSERT SELECT startup work. Desktop and daemon pass server limit; daemon removed global fallback and propagates cursor; protocol has ThreadListFailed and next_cursor. Shared sidebar uses explicit Initial/Loading/Ready/Error state and preserves stale rows; no `unwrap_or_default` false empty. ProviderCatalog now returns stale disk cache immediately, parses/reads/writes off async executor, and performs lazy background single-flight refresh; no startup prefetch. Config defaults reuse loaded workspace runtime immutable config instead of rescanning; backend GUI JSON has mtime/length cache with write invalidation. Desktop agent/model/session/skill pickers open immediately and fetch on worker threads; config defaults use background retry and a truthful 12s one-time plugin-generation budget. Tests added for equal-timestamp session paging/mutation projection and sidebar stale/error semantics. Important files: agent-server state.rs/v2_routes.rs/session_routes.rs/plugin_adapters.rs; provider_catalog.rs; shared side_panel.rs/draw.rs; desktop pane input/session/ingest/render_state; protocol agent.rs; daemon handlers.rs.
