# Streaming CSV reports

Repair `pipeline.summarize(lines, options)`. This synthetic stdlib project separates CSV/schema handling, decimal aggregation and orchestration. Lines is a one-pass iterable of strings suitable for Python csv.reader (physical lines, including line endings); support lists and generators without a second iteration. Reject scalar strings, dicts, null and non-iterables as invalid_lines. Every element must be a string. No filesystem or network.

Options is exactly `{group: nonempty_string, amount: nonempty_string, where: null_or_filter, min_amount: null_or_decimal_string}`. Group and amount may name the same column. Filter is exactly `{column: nonempty_string, value: string}`. Decimal strings, after stripping surrounding whitespace, match `[+-]?(?:[0-9]{1,18}(?:\.[0-9]{1,6})?|\.[0-9]{1,6})`: no exponent, NaN, Infinity, underscores or trailing decimal point. min_amount uses the same grammar. Options validation occurs before reading lines; invalid options yields invalid_options.

Read CSV with comma delimiter, standard double-quote escaping, and strict=True. First CSV record is the header; remove one leading BOM from its first field only. Require nonempty unique header names and the named group/amount/filter columns; otherwise invalid_header. Header names, group keys and filter values are exact strings, no trimming/case conversion. Empty input is invalid_header. Embedded quoted commas/newlines must work. Logical CSV records (not physical lines) are numbered from 1 for header; blank records count and have wrong width.

For each data record: first reject width mismatch as `{row: logical_number, code: "width"}`; then apply exact where equality (nonmatches increment filtered and do not parse amount); then validate amount (bad amounts append `{row, code: "amount"}`); then apply inclusive min_amount (values below threshold increment filtered); then aggregate raw Decimal amounts by group, increment accepted and group count. Row errors are collected in input order, omitted from aggregation and counts. Sum raw values before rounding once per group with ROUND_HALF_UP to 2 places; normalize rounded negative zero to `"0.00"`. Groups sorted by key (Python string order). Return `{groups: [{key, count, total: string}], accepted: int, filtered: int, errors: [...], error: null}`.

Fatal errors are atomic: return groups/errors empty, accepted/filtered 0 and error `{code: CODE}`. CSV parsing failure yields invalid_csv; non-string line element yields invalid_lines. Fatal errors discard earlier row errors and totals. Input containers must not be mutated. Fatal errors are reported when encountered; processing may stop immediately without consuming the remaining stream. Run `python -m unittest discover -v` in workspace.
