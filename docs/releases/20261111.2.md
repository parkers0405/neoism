# Neoism v0.7.149-nightly.20261111.2

This Rune nightly follows `20261111.1`.

## Changes

- Closing the lid and opening it again brings every conversation and sub-agent back where its agent is now. A quiet connection to the daemon is pinged and a dead one is dialed again within seconds of waking; each open conversation is then followed from its live end and takes its newest history page over what is loaded, so nothing that was missed is replayed and all of it is in the history. Before, a new connection followed nothing: an open chat stayed frozen until it was reopened. An SSH workspace dials its tunnel again when it is lost with the link.
- An interrupted read on the daemon connection no longer counts as a disconnect.
- The agent server retries a provider stream that stays silent for 30 seconds after the host wakes from sleep, while no tool call of that step has run. Before, it waited out a five minute idle watchdog whose clock does not run during suspend.
- The daemon tells clients when its own event stream from the agent broke and reopened, and the app refreshes that conversation's family from history.
- A native Git changes panel with a unified review.
- Prompts sent while the agent is at work show as queued under the activity line and enter the transcript when the agent takes them. Esc stops the run at once when work is queued.
- A long reply streaming over a long agent run drops fewer frames: a reply is drawn a heading's worth at a time, each piece cached, so only its last piece is rebuilt as text arrives.
- A refreshed conversation list stops the loader of a chat that finished; reasoning wraps to the available width; a finished terminal block keeps its tail in view.

## Validation

The Rune app's 347 tests pass at this commit. Sleep and wake were exercised in a real window against the previous nightly's daemon and agent (`rune/scripts/check-sleep-resume.py`): the app was stopped and its link made silent in the middle of a real reply, for a main conversation and for a sub-agent being viewed, and the transcript it ended with matched the same conversation opened fresh, row for row (reconnected 4.6 s after waking over a dead link, 0.1 s with the socket intact). The SSH tunnel redial was not exercised. The agent server's wake retry is covered by its unit tests only, and the daemon's resume event was not seen live. Streaming a 50 KB reply over a 5 MB conversation shown as one live turn missed 3.8 to 5.3% of frames at 120 Hz before and 0.8 to 1.3% after. The Git panel and queued prompts are covered by their unit tests; they were not checked separately for this note. One daemon test, `transport_created_at_history_preserves_user_tool_and_canonical_order`, fails at this commit and at the previous nightly's. The macOS and Windows builds are gated by CI only.
