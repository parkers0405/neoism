# Neoism v0.7.157

Release preparation date: 2026-11-16 (host local date).

## Frame pacing, Agent scheduling, and Rune presentation

- Adds presentation timestamp and frame-pacing instrumentation. Window-local FPS status measures completed presentations where available and explicitly labels submission fallback rather than treating CPU encode spacing as display throughput.
- Refines idle and streaming Agent scheduling and pinned timeline presentation; question-rail highlights use live values without rebuilding the view.
- Fixes Rune live-value remounting, scroll anchors, and text layout, preserving authored text measurement and adding regression coverage for remounts, anchors, scrolling text, and presentation summaries.

## Verification status

No local tests were run for this release. This stable release includes the current workspace changes and is prepared for immediate full GitHub release without a preflight or test gate before tagging. Existing GitHub checks remain unchanged; added regression tests are not claimed as locally executed for this release.

## Release packages

Linux x86-64, macOS ARM64, and Windows x86-64 build from the stable tag. All three platforms publish independently: each successful platform publishes without waiting for the others. The daemon container image retains its separate workflow.
