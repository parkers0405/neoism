# Neoism v0.7.149-nightly.20261111.5

This Rune nightly follows `20261111.4`.

## Changes

- Right-click menus. A file or note row offers Edit / Open, New File, New Folder, Rename and Delete; the blank space under the rows offers New File and New Folder at the root; a chat row offers Pin / Unpin Chat, Rename Chat and Delete Chat. Each row shows the letter that picks it, and anything that needs a name or a yes asks in a small card first.
- A file, note or folder can be dragged into another folder. The row dims in place, a copy follows the pointer, and the folder it would land in is tinted and shivers; a closed folder hovered for 450 ms springs open. A drop on a folder goes into it, on a file beside that file, on blank space into the root. Dropped back on itself, on its own folder or outside the sidebar, it stays where it is.
- Notes always open the default vault. A vault linked to the project is no longer followed.
- In the command palette, `w` or `write` saves the open file and `wq` or `x` saves and closes it (beside the existing `q` and `q!`).
- Escape in normal mode puts a `/` search's highlights away.
- Pending questions and permission requests keep the conversation they came from and show by family membership; the daemon sends the authoritative list of pending permissions.
- An edit arriving from outside lands with a brief flash, in code and Markdown.
- A finished chat's cached running state is cleared on completion and on reconnect or reset.

## Validation

The Rune app's 372 tests pass at this commit, and a local build of it was installed and used. Seen in a real window: the right-click menu and the rename card (opened by a test hook rather than a mouse press), a delete through the menu against a real daemon, and the default vault being returned for a project. The drag-and-drop rules have unit coverage; the drag itself, rename and New File from the menu, the palette's write commands and Escape clearing the highlights were not exercised by this note's author. The tree menu does not yet have GPUiX's Copy, Paste Here and Show Dotfiles, sub-agent rows have no menu, and deleting or renaming a file does not close or re-point a tab that has it open. The macOS and Windows builds are gated by CI only.
