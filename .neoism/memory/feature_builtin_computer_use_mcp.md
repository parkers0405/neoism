Built-in `computer` MCP lives in neoism-agent/crates/neoism-agent-server/src/computer_use.rs + computer_use/platform.rs + computer_use/shortcuts.rs. Registered in AppState open_storage_with_services (linked server; no helper executable/custom GUI). Tools capabilities/screenshot/input/stop; input move/click/drag/scroll/text/key.
ACTIVATION CORRECTION: enabling computer in the EXISTING MCP picker is sufficient. Disabled by default, but NO environment gate or restart requirement. Removed old host activation checks and metadata from code/help/docs. Do not reintroduce a second host opt-in. Session executor still enforces scoped computer_use permission (generic wildcard allows excluded, denies preserved; existing dangerous skip mode applies); OS permissions remain mandatory. Direct MCP HTTP wrappers pass session_authorized=false so screenshot/input forbidden.
Admission revocation/shortcut fixes described in bug_computer_use_admission_and_shift.md remain intact: capture generation before reading enabled config; carry exact epoch into run_worker (no refresh), preventing disable races and stale-lease bypass. Per-process try-lock serialization, ten-second response/action timeout, cancellation checks between events; native blocking calls cannot be preempted and may retain lock. Frame tokens expire30sec, bounds/topology validation, stop invalidation. Captures <=64Mpx, thumbnail<=1600px, PNG<=8MiB. BuiltinMcpContent::Image converted to McpContent::Image; agent_tool_registry normalizes images to metadata.attachments for provider media.
Linux: libwayshot0.8 + Enigo0.6.1 Wayland-only, no grim/ydotool/root/XWayland fallback. screenshot_outputs(single selection) applies rotation unlike screenshot_single_output shortcut. Pointer remains single-output-only. Shortcuts resolve raw XKB codes before modifiers, same codes down/up; reject ambiguous seat/layout. Mac: XCap/CoreGraphics, ScreenRecording and Accessibility; paired direct Unicode CGEvents. Windows: XCap, scoped per-monitor DPI SetCursorPos, explicit Unicode SendInput pairs, stable shortcut VK codes. Modifier/button cleanup preserved.
Latest correction verified with former activation variable explicitly unset in shell: cargo test -p neoism-agent-server computer_use --lib (14 passed), mcp::tests (18 passed), cargo check -p neoism-agent-server -p neoism-agent-service-api, git diff --check. Integration test computer_use_picker_activation_needs_no_restart_and_preserves_boundaries uses task-scoped cfg(test)-only mock backend through actual MCP/service/worker admission. Disabled default calls=0, enable same server+old lease yields exactly1, direct calls denied, disabling again leaves count1. TEST_REVOCATION_LOCK serializes stop-mutating tests to avoid positive-admission flakiness. No native desktop actions performed. Earlier exact-source macOSARM64/WindowsMSVC isolated cross-checks passed; no native OS runtime verification. Docs neoism-agent/docs/computer-use.md. Preserve unrelated concurrent changes.
