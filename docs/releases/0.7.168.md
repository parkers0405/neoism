# Neoism v0.7.168

This release makes Agent activity easier to follow, adds wallpaper controls, and improves workspace switching on macOS.

## Agent

- In a focused conversation, the latest thought stays visible while its tool calls run inside a closed Working group.
- When a provider repeatedly retries a request, a warning appears below the activity line and clears when the turn recovers or ends.

## Appearance

- Go to Settings > Backgrounds to adjust pixelation and dithering alongside opacity and blur. Slider changes preview live and save when you release the slider.

## Workspaces and terminal

- On macOS, choosing a directory can move the main integrated bash or zsh terminal to that folder. Neoism waits for confirmation before switching the workspace.

## Validation and downloads

Linux x86_64, macOS Apple Silicon, and Windows x86_64 build, test, and package independently from the same immutable stable tag. The daemon image uses the same tagged source. Local checks, publication and checksum verification are reported separately; this is not a claim of manual GUI testing on every platform. The macOS bundle is signed with a Developer ID and publishes only if Apple notarizes it.
