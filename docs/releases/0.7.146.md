# Neoism v0.7.146

This stable update completes the sidebar mouse-focus and keyboard-cursor fixes with coverage through actual native GUI input.

## Fixes

- Apply keyboard-focus preservation to each activity-rail hit region, not only its wrapper, so native mouse handling keeps the editor/composer focused when opening Files, Notes, or Conversations.
- Clear sidebar ownership before mounting a replacement panel during a mouse toggle, preventing the new tree from taking focus during mount.
- Reclaim tree selection and cursor ownership when a navigation key is delivered after an Agent-to-Files handoff or delayed native blur. Repeated arrow keys now move the visible cursor with the selected row instead of leaving it parked at the handoff position.
- Extend regression coverage for delayed blur, repeated Down movement, and dirty-document preservation. Native GUI automation uses real hit testing, a larger file fixture, deterministic cursor bounds, and draft-preservation assertions across mouse and Alt/Option navigation.

## Downloads and provenance

Linux x86_64, macOS Apple Silicon, and Windows x86_64 bundles are built from the same immutable stable tag on `main`. macOS includes a DMG and Windows includes an MSI. Every payload has a SHA-256 sidecar, and each platform includes exact source/version metadata. Unchanged shared documentation remains pinned to its published revision.

Private `.neoism` configuration and memory, local histories, ignored debug wrappers, and local build artifacts are excluded from the source release.
