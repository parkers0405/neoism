# Neoism v0.7.152

This stable release includes the current native Rune frontend and Agent/workspace improvements.

## Changes

- Native touch panning and drag arbitration, scrolling and selection refinements, configurable fonts and keybindings, and macOS glass cursor rendering with ordinary fallback behavior elsewhere.
- Agent goal lifecycle and completion feedback, activity presentation, slash commands, tool cards, and conversation controls.
- Workspace file handling, connection and server-availability feedback, compact finder/palette layouts, and Linux updater restart improvements.
- Pinned vendored Rune input/rendering changes, including upstream GPU libraries and binary fixtures required for fresh checkouts.

## Release packages

Linux x86-64, macOS ARM64, and Windows x86-64 build from the same stable tag. Each platform uploads its downloads and publishes the shared release as soon as its own job succeeds; another platform's failure does not block it. The daemon container image uses its separate workflow.

No local test suite was run for this release. Existing GitHub platform build, test, and packaging steps remain enabled; this is not a claim of exhaustive GUI, provider, touch-device, or cross-platform validation. Existing database backup and downgrade cautions remain applicable. Ignored local build outputs and private workspace state are excluded.
