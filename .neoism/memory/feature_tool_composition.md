Tool Composition implemented as built-in `compose` in ordinary agent server / default desktop dependency graph. No feature flag, separate executable, Node/Bun/Python, interpreter download, or ambient JS engine. Pure Rust standalone `neoism-agent/crates/neoism-agent-composition` uses pinned Oxc 0.95 parser -> whole-program validated owned IR -> async Rust evaluator. Root workspace member/dependency, server unconditional dependency and Workspace tool registry entry. MIT Oxc attribution added NOTICE + misc/licenses/oxc.txt.

Runtime supports defined JS subset: bindings, shared arena object/array identity, safe member mutation, arithmetic/conditions/loops incl correct per-iteration for-let capture, functions/arrows/async, await/try-catch, data transforms, JSON/Object/Math/string helpers, bounded logs, fail-fast Promise.all and allSettled. No imports/eval/new/classes/templates/destructuring/spread/regex/optional chaining/etc. README documents deliberate deviations: async Rust-task scheduling (not JS synchronous async prefix), sequential function declarations, Unicode-scalar indices, array assignment only existing indices. Local cycles/prototype keys blocked. Undefined rejected in explicit tool data; no-return output null; stringify undefined follows object omission/array null rules. Safe integral numbers serialized as JSON integers for native u64/usize; unsafe integers diagnosed, IDs should be strings.

Defaults: 120s wall,100k steps,64 calls,8 runtime concurrency (server leaf scheduler4),64KiB source/output,16KiB logs,16MiB cumulative logical data,depth64,250ms cleanup. Conservative lexical guard before parser rejects recursive hazards; subprocess regression prevents stack abort from generated with/control/unary/exponent cases. Allocation-counting JSON preflight, admission before clones/trim/logs, capped serializers, cooperative fuel/cancellation. Run-owned tasks cancel/join/abort on end/drop; resource aborts noncatchable. Logical budget isn't exact process RSS.

Server `src/tool_composition.rs`: scoped captured native+MCP catalog inherits provider/permission/execution/model eligibility and pinned plugin generation. Native paths neoism.<id>, MCP namespaces preserved; search returns exact tools.<namespace>.<name> and signatures. Explicit exclusions compose,execute,task/task_result/stop_task,question,plan_enter/exit,complete_goal,move_chat,background_task/results. MCP calls through existing execute gateway (not raw runtime IDs); schemas validated before and after hooks, approvals resolve per child without script replay. Cancellation-aware permission waits clean local pending requests without aborting session. Optional scoped ProgressSink updates authoritative parent message only; no child provider Part::Tool messages. Child-local supervisor uses Weak host ownership/AbortOnDrop, bounded cleanup, reports `partial_unknown` rather than pretending rollback. Malformed/oversized MCP entries omitted with bounded warnings; oversized signature falls back unknown but full schema authority retained; reserved neoism namespace/collisions cannot shadow native. Schema/signature/catalog aggregate bounds and offline jsonschema default-features=false.

Host results explicit {title,output,metadata,isError}; only actual raw MCP structuredContent also exposed data/structuredContent, no guessing formatted text as JSON. EffectSink retains only snapshots/artifacts/diffs/files/media/generatedFiles, not raw MCP intermediate bodies; records before fallible after-hooks. Root effects/media/undo preserved even failure; Error state metadata.toolResult consumers updated. isError:true on failed composition. Parent metadata.composition contains toolCalls (running/completed/error/partial_unknown), value,error,logs,warnings,truncated. UI shared agent_pane/composition.rs has bounded64-call history, source/result cards via existing diff_card machinery, final trace outranks stale live trace, no separate child model replay. Docs bundled page 'Neoism Agent/Tool Composition.md', linked agents/tools guides. Added native Linux/macOS/Windows CI matrix .github/workflows/tool-composition.yml.
