# Neoism v0.7.159

This stable release brings the native Markdown editor, Notes workflows, Mermaid previews, and the latest editor and connection fixes to Linux, macOS, and Windows.

## Markdown and Notes

- Native Markdown live preview and source editing with headings, formatting, checkboxes, tables, code cards, images, links, page decorations, block dragging, collaboration, and presence.
- Native Mermaid previews in notes and agent replies with source access, copying, larger previews, bounded background rendering, and editable source on errors.
- Markdown section-fragment navigation, including encoded headings, duplicate-heading suffixes, and asynchronous file loading.
- Optional Markdown spelling underlines and correction menus, configurable in Settings through `editor.markdown.spellcheck`. Spellchecking defaults off, supports ignored words and a custom dictionary, and uses native spelling support on macOS. Markdown does not attach to language servers.
- Notes creation, nested paths, folders, rename and delete shortcuts. Renames preserve live buffers, unsaved text, undo and collaboration identity; external edits highlight affected rows without taking focus.

## Editor and connections

- Soft-wrap, caret, presence and diagnostic layout improvements, plus sidebar and terminal presentation updates.
- Tab-reorder shortcuts recover when a workspace switch interrupts a pointer drag.
- MCP browser authorization completes the server connection and refreshes the tool catalog. Connection dialogs show completion and failure states and can be dismissed.

## Validation and downloads

Linux x86_64, macOS Apple Silicon, and Windows x86_64 build, test, and package independently from the same immutable stable tag. The daemon image uses the same tagged source. Local checks, publication and checksum verification are reported separately; this is not a claim of manual GUI or live-provider OAuth testing on every platform.
