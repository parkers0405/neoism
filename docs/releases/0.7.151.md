# Neoism v0.7.151

This stable update includes the current remote/headless authentication fixes and Docker hosting validation tooling, alongside the Rune app and services from v0.7.150.

## Authentication and hosting

- Prefer OpenAI and xAI device authorization for hosted or explicitly headless provider requests. Docker images set NEOISM_AGENT_HEADLESS=true; CLI authentication can print authorization links without launching a browser.
- Permit narrowly scoped worker provider-authentication operations without opening unrelated operator APIs or allowing read-only tokens to manage credentials.
- Route MCP browser callbacks using one-time state before plugin generation, preserve tenant/workspace scope, reject forged directory input, and avoid recording query secrets in request spans. Callback responses disable caching and referrer forwarding.
- Support an explicitly configured public MCP OAuth base URL with validated HTTPS and encoded server names; explicit per-server redirect URIs retain precedence.
- Harden remote CLI requests with HTTPS, no redirect following, and explicit remote credentials rather than forwarding a local Agent token.
- Include remote authentication guidance and an isolated real-image Docker harness for workspace joining, tool execution, persistence, restart recovery and explicit-stop behavior. The recorded Docker validation describes v0.7.150; it is not a claim that the new v0.7.151 image or paid-provider OAuth has already been tested live.

## Release packages

Linux x86-64, macOS ARM64 and Windows x86-64 bundles build the Rune app and bundled services from the same immutable stable tag on main. The daemon container image is published by its separate release workflow. Desktop downloads include exact source/version metadata and SHA-256 sidecars.

Automated authentication and packaging checks do not establish exhaustive live-provider, public-ingress, manual GUI or cross-device validation. Existing database backup and downgrade cautions remain applicable. Private .neoism files and ignored local artifacts are excluded.
