# Neoism v0.7.164

This stable release simplifies the focused Agent view introduced in v0.7.163, on Linux, macOS, and Windows.

## Focused Agent view

- A turn now has two states, and the arrow on its work row says which.
- **Folded** (arrow pointing right), whether the turn is running or done: none of its tool calls show. You see your prompt, the work row, everything the Agent wrote in order (its notes on the way and the reply) and, while it runs, the thought it is having.
- The work row reads "Working · 9 steps · 1 file changed" while the turn runs, with a shimmer and dots that count up, and "Worked" once it is done. Failures are counted in red.
- **Open** (arrow pointing down, after pressing the row): the whole trace, every call as its card with output and diffs, held in place under the pointer. Pressing the row again folds it.
- The running turn no longer lists its calls as single lines between the notes; that list is replaced by the work row's live count.
- Unchanged: a sub-agent still at work keeps its card until it finishes; checklists, your own shell commands and notices always show; Settings > Agent > **Focused agent view** turns the view off.

## Validation and downloads

Linux x86_64, macOS Apple Silicon, and Windows x86_64 build, test, and package independently from the same immutable stable tag. The daemon image uses the same tagged source. Local checks, publication and checksum verification are reported separately; this is not a claim of manual GUI testing on every platform. The macOS bundle is signed with a Developer ID and publishes only if Apple notarizes it.
