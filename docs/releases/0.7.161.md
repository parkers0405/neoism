# Neoism v0.7.161

This stable release adds Sign in with ChatGPT, signs and notarizes the macOS build, and fixes the Agent stopping short in long conversations, on Linux, macOS, and Windows.

## Sign in with ChatGPT

- OpenAI now has one sign-in for ChatGPT plans: **Sign in with ChatGPT**. It opens in the browser and connects on its own, with no device code to enable in ChatGPT settings and no fixed local port that another app can hold.
- It offers the current GPT-5.5, GPT-5.6, GPT-6, GPT-6.1 and GPT-6.2 models on your plan, shown at no cost.
- The Codex browser and device-code sign-ins are no longer offered, because OpenAI only accepts device codes for accounts that enabled them. Existing Codex connections keep working. Set `NEOISM_AGENT_OPENAI_CODEX_AUTH=1` to offer them again, for example for an agent running on a remote machine, which cannot receive the browser callback.
- Plan usage and image generation are not available with this sign-in; they still need a Codex connection or an API key.

## Signed macOS builds

- The macOS app and disk image are signed with a Developer ID (Synapse AI Solutions LLC) under the hardened runtime and notarized by Apple. A downloaded Neoism opens without a Gatekeeper warning.
- A stable signing identity lets macOS keep privacy permissions such as Accessibility and Screen Recording attached to Neoism across updates.
- Agent computer use asks macOS for Accessibility the first time it needs it. That prompt also lists Neoism under System Settings > Privacy & Security > Accessibility, where it can be enabled.
- macOS can now ask for permission when a program running in the Neoism terminal wants to control another app.

## Agent

- After a long conversation is compacted, the summary of earlier work is delivered as background instead of as standing instructions. Its old goal, constraints, blockers, and next steps no longer outrank later requests, which had caused the Agent to report status instead of doing the work.
- Conversation summaries no longer record the summarizer's own limits as constraints, keep only standing rules, and list the most recent unfinished request first.
- The Agent ends a turn to wait on delegated work only after it has actually started that work.

## Validation and downloads

Linux x86_64, macOS Apple Silicon, and Windows x86_64 build, test, and package independently from the same immutable stable tag. The daemon image uses the same tagged source. Local checks, publication and checksum verification are reported separately; this is not a claim of manual GUI or live-provider OAuth testing on every platform. This is the first release notarized by Apple: the macOS bundle publishes only if Apple accepts it.
