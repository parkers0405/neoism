# Neoism v0.7.167

This stable release improves multiline Git commits, trackpad scrolling in Agent conversations, and zsh terminal history.

## Git panel

- Press Shift+Enter to add a line to a commit message. The box grows as you type, then scrolls once it reaches its height limit.
- Collapsed files no longer leave blank gaps between their diff headers. Review toolbar tooltips appear above the content.

## Agent

- On macOS, a trackpad swipe in a conversation slows to a smoother stop when momentum reports arrive farther apart.

## Terminal

- Integrated zsh terminals keep command history when you close a tab. Neoism also looks for history in your custom `ZDOTDIR` and respects your shell's history settings.

## Validation and downloads

Linux x86_64, macOS Apple Silicon, and Windows x86_64 build, test, and package independently from the same immutable stable tag. The daemon image uses the same tagged source. Local checks, publication and checksum verification are reported separately; this is not a claim of manual GUI testing on every platform. The macOS bundle is signed with a Developer ID and publishes only if Apple notarizes it.
