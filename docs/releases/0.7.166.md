# Neoism v0.7.166

This stable release brings branch changes, GitHub pull requests, and issues together in Neoism's Git panel.

## Git panel

- Click the branch pill in the status bar to open the panel. Find, switch, or create branches, select files to stage, and use the action button to commit, sync, publish, or open a pull request.
- Review all changed files in a single diff. Navigate with the file tree and sticky file headers, choose stacked or side-by-side layouts, and turn wrapping off to scroll long lines horizontally. Add a file-and-line reference to your Agent draft directly from the diff.

## GitHub pull requests and issues

- Browse pull requests, inspect diffs and checks, follow conversations, and review changes with comments, approvals, or change requests. Check out or merge a pull request from the panel.
- Read and reply to GitHub issues, or start an Agent chat from one. The hosted views use `gh` through the workspace daemon.

## Agent tabs

- See when an open conversation is running, working in the background, compacting, or waiting on you from its tab icon, even with the Conversations sidebar closed.

## Validation and downloads

Linux x86_64, macOS Apple Silicon, and Windows x86_64 build, test, and package independently from the same immutable stable tag. The daemon image uses the same tagged source. Local checks, publication and checksum verification are reported separately; this is not a claim of manual GUI testing on every platform. The macOS bundle is signed with a Developer ID and publishes only if Apple notarizes it.
