# Neoism v0.7.149-nightly.20261110.2

A follow-up to the first Rune nightly, from the first use of it on macOS and Linux. Stable remains on v0.7.148.

## Changes

- macOS and Windows: the app draws its own title band. The macOS traffic lights sit in it instead of over the activity rail, and Windows gets its minimize, maximize and close buttons. The band is hidden in full screen.
- macOS: Option is Alt, so every Alt shortcut (Option+E, A, N, C, D, S, P, T, 1-9) is heard. Shortcut labels read Option. Option no longer types accented or special characters inside Neoism.
- A code or Markdown file keeps its scroll position while another tab or workspace is showing.
- The file tree lists itself whenever it shows empty: a sidebar restored with the window, or opened before the daemon answered, no longer stays blank until toggled.

## Known gaps

- The title band and the Option handling could not be exercised on Linux, where this build was developed: they follow the toolkit's documented behaviour and have not been seen running on macOS or Windows.
- The Windows build has still not been used by a person.
