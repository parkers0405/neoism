# Neoism v0.7.170

- **Phone pairing:** Open the QR control in desktop Neoism to share your workspace with the companion app. The phone app continues to ship separately through TestFlight.
- **Subagent defaults:** Choose a workspace-wide harness, model, and reasoning level for new subagent runs.
- **Desktop polish:** Updated native file pickers and app icons, plus keyboard and touch input fixes in Rune.

Linux x86_64, macOS Apple Silicon, Windows x86_64, and the daemon image build independently from the same stable tag.
