Workspace-level Conversations sidebar: native desktop Rust GUI and shared web Chrome, Alt+C/topbar. Files/Notes visibility restored on close. Two-line date-grouped source-icon/title/time rows; search, paging, pin/rename/delete Neoism sessions. Right detail panel chat-only, active/wide/unhidden; Back and duplicate session list removed. Four ConversationSource values: Neoism Agent, Claude Code, Codex, OpenCode.

ACP roots are first-class Neoism sessions created from the UI. `POST /v2/sessions` accepts optional `externalProvider` opencode|claude|codex and stamps these roots with `externalAgent.historyState = "neoism_only"`. Root immutable metadata routes queued prompts through workspace-owned ACP while preserving Neoism timeline/SSE/events, permissions, abort, statuses, tool parts, inferred child sessions, and plans.

2026-10 Conversations overhaul: preserve Press Start 2P typography/extrusion/drop caps/date headers but scale it with global `chrome_scale`; titles use the shared BufferTabs 600ms hover marquee and clipped stable session identity. Sidebar default width is 340 logical px (resizable 180-700) on desktop and shared Chrome, retained across per-workspace pane swaps. Alt+1/2 parks/restores each workspace's complete conversation pane, catalog, scroll, pagination, and caches. Refresh/reconciliation preserves stable selected and first-visible identities. Rendering avoids full catalog/subagent clones, unnecessary branch reconciliation, unbounded overlay retention, and per-frame provider scans.

Composer rule: retain the row under the input. Neoism keeps agent/model/thinking controls. OpenCode ACP keeps canonical mode/model/thinking controls. Codex and Claude ACP keep model/thinking only because ACP `mode` is protocol metadata and Codex uses it for approval policy. No generic Provider Options, loading/retry/review, ellipsis, or overflow chip. Every provider-advertised config selector, including noncanonical settings such as Fast mode, appears directly as its own entry in the standard `/` picker above the input and opens its choice picker directly. There is no synthetic `/options` menu or overflow picker; a real provider-advertised slash command named `options` is still treated as that provider's command.

Provider history import is no longer part of Conversations. Desktop external catalog scanning/import-on-click/background ingestion was removed. Root list ownership is strict: ordinary Neoism sessions (no `externalAgent`) and external ACP roots with exactly `historyState = "neoism_only"` are visible; `text_only`, `importing`, `not_loaded`, or unmarked external roots are hidden. The ownership predicate is applied inside the indexed SQL query before pagination, then again server-side and in desktop mapping as defense in depth. Compact index metadata retains sourceHost/sourceKey. Do not restore automatic Codex/OpenCode/Claude history discovery.

Left Conversations and right in-chat details are independent surfaces and independent geometry. Conversations defaults to 340 logical px and remains right-edge resizable from 180-700. The right details rail is fixed at 260 logical px, shrinking only to preserve the 520px chat minimum; it must never inherit Conversations width or resizing. `agent.conversations-panel-enabled` and `agent.details-panel-enabled` are grouped default-on availability gates. Disabling either immediately closes and blocks only that surface. Alt+A opens the Agent and auto-shows Conversations without taking composer focus. Alt+H always toggles the right detail rail, including while an Agent subsurface is focused, and never toggles Conversations. Desktop and shared/web follow the same policy. Top-chrome active states color the complete icon glyph for menu, folder, Notes, Conversations, Search, and details; the old half-glyph repaint path is removed.

ACP stream invariants: ACP assistant steps start without a speculative empty text part. The first text chunk is inserted at its true timeline position; consecutive chunks share the final text part, while text resumed after a tool creates a new part. Tool updates mutate stable part IDs in place. ACP finalization preserves streamed text segments instead of replacing an earlier placeholder, so tool cards cannot move behind later final text. Native providers retain eager single-text behavior.

Inferred ACP subagent invariants: a successful terminal update to the parent task tool projects terminal output but does not complete the inferred child. Explicit failed/error updates may terminalize it immediately. Remaining children settle with the parent turn: successful turn to `completed`, failure to `error`, cancellation to the interrupted path. While a child is active and the parent is in tool-working state, shared and desktop composer status is `Sub-agents working`; active main-text generation still takes precedence.

Usage invariants: `TokenUsage.contextLimit` is durable and accepted from camelCase or snake_case. ACP usage accepts `contextLimit`, `contextWindow`, snake_case equivalents, and `size`; absent values may be resolved from selected ACP model option metadata or Neoism's model catalog (Anthropic fallback for Claude, OpenAI fallback for Codex). Show a context bar only with a real denominator, and preserve it through live events, step finish, and reload.

ACP runtime invariants: npm ACP adapters resolve Neoism's managed Node 22 `npx` before PATH and prepend its bin directory because the `npx` launcher uses `/usr/bin/env node`. Use Neoism's dedicated `npm-acp` cache rather than the user's global npx cache; an interrupted global install can retain package files without the `.bin` link and fail as `claude-agent-acp: command not found`. ACP process failures retain a bounded 8 KiB stderr tail and report command identity, exit status, and stderr. Do not regress to PATH Node, the global npx cache, or discarded adapter diagnostics.

A real `@agentclientprotocol/claude-agent-acp@0.81.1` initialize request succeeds under managed Node 22 and the dedicated cache. Provider footer and shared/desktop subagent status tests pass. `cargo check -p neoism`, WASM `cargo check`, web TypeScript typecheck, `cargo fmt --all -- --check`, and `git diff --check` pass. Existing unrelated warnings remain. Native live visual verification of footer controls, usage bars, branch streaming, status text, and card ordering remains manual.
