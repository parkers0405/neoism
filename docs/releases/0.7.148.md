# Neoism v0.7.148

This stable update improves Agent history paging and refresh work, keeps local workspaces available when the Agent service is unavailable, and restores program-aware Home tab titles. It includes the glyph-cache correction from v0.7.147.

## Changes

- Adapt older-history page sizes to message bytes and prefetch smaller pages earlier. Refresh hydrated transcripts with changed-row updates when order is preserved instead of resending the complete loaded history; fall back to full history for inserted or reordered rows.
- Apply queued Agent events after the display frame batch commits, reducing interference with the frame already due.
- Keep local workspaces online independently of Agent availability and remove background catalog warnings from the composer.
- Show Claude, Codex, and OpenCode titles and icons on the Home shell tab while those programs run, then restore Home when they exit.
- Add opt-in per-frame trace attribution and an analysis script. Trace logs record timings, sizes, and message kinds rather than message contents.
- Include the published documentation update and regression coverage for history ordering, adaptive paging, and Home tab titles.

## Downloads and verification

Linux x86_64, macOS Apple Silicon, and Windows x86_64 bundles use the same immutable stable tag on main, with source/version metadata and SHA-256 sidecars. Private .neoism files and ignored local build artifacts are excluded. Platform CI validates builds and packages; no new manual macOS or Windows GUI validation is claimed by these notes.
