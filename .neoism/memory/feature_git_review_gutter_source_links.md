Wrapped continuations/removals/hunks/placeholders/left split/history are inactive. Code-body clicks remain inline. Native open_git_diff_source_location forces ordinary source tab only for gutter navigation; generic LSP same-file navigation unchanged. Reuses canonical CodePane or existing Markdown owner (jump_to_line raw source coordinates), with separate path-qualified pending locations until remote text loads; dirty text/undo preserved. Native window cursor-left and shared PointerLeave clear hover. Web uses typed GitDiffSourceOpenRequest queue -> WASM drain -> TerminalPanel.openGitDiffSource, source tab metadata installed before activation, canonical active/parked CodePane+binding reused, path-qualified pending goto and stale-read guards. sourceCode tab metadata forces CodePane source presentation for newly opened .md/.ipynb/.neodraw as well.
