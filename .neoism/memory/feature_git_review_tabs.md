Git review workflow redesigned from screenshot requests. Rich Git sidebar is right-docked with no embedded preview; Tracked/Untracked collapsible file lists, pinned branch + real upstream-aware Publish/Push split button and action menu, then commit area. Shared code: panels/git_diff. IMPORTANT subsequent user correction: ONE repository-wide 'Uncommitted Changes' review tab, NOT one tab per file. GitDiffView now reconciles all FileChange entries with set_files, accepts per-file patches via set_file_lines, folds sections independently on header click/Enter, and reveal_file opens/jumps to requested section. Native/web deduplicate root-scoped review routes, preserve collapse/scroll across tab replay and status updates, and keep editable file/Markdown tabs separate. Only visible file sections/rows render; toolbar measures actual label width with compact fallbacks so Split / Unified [Tab] never uses a guessed fixed width. Each shared file header spans both split columns; diff_card's duplicate headers are clipped away. Native request_review_diffs uses one single-flight background worker per repo revision, sequentially loads missing patches (selected first); joined desktop HostGitIo sends one DiffFiles batch. Native render polls while loading even if sidebar closes. Sidebar viewport/scroll/reveal/scrollbar share exact pixel bounds and bottom corner inset; clamp stale springs after collapse/resizing so final row fully reveals. Interactive Git rows/buttons and diff headers/toggle use pointer cursor; commit/filter text inputs alone I-beam; blank review body default. Desktop native bridge git_diff_view_pointer_at + wasm active_diff_cursor wire cursor ownership. Normalize host paths via neoism_protocol::host_path::HostPath, not std::Path stripping foreign Windows roots; normalize before replay identity comparison. diff_lines_for_path returns Some(empty) for clean/disappeared changed paths after successful status to avoid stale committed diffs. Web legacy patches ignored once provider exists, clean status invalidates in-flight old diff batch. Publish: GitClientMessage::Publish WriteFiles mutation, upstream metadata on GitRepoStatus/ChangedFiles; selects branch.pushRemote -> remote.pushDefault -> origin -> sole remote, rejects ambiguity/detached/unborn/no remote, explicit same-name refspec and set-upstream, no force. Apply upstream AFTER host_set_repo/host_set_branch resets. Commit drafts clear only confirmed success matching submitted text (native worker completion, desktop pending_commits by id, JS service -> git_panel_commit_succeeded).
