# Neoism v0.7.143

This stable release brings the native GPUIX desktop and the accumulated workspace, terminal, editor, agent, authentication, packaging, and documentation changes from `fix/gpuix-chat-performance` onto `main`.

## Highlights

- Native agent orchestration and ACP lifecycle, child streaming, model selection, session recovery, direct shell blocks, and timeline rendering improvements.
- Installation-wide MCP enable/disable preferences without copying workspace transports or secrets into global configuration, with matching API, OpenAPI, SDK, and documentation updates.
- Restored context usage for reopened conversations, including configured model aliases and valid limit fallback; goal state hydration and live updates in the details rail.
- Faster command palette selection and scrolling through retained catalog rows; Finder and sidebar keyboard focus/navigation refinements.
- Native desktop, terminal, editor, workspace startup/isolation, authentication, and platform fixes accumulated throughout the preceding nightly series.
- Windows GUI launcher enforcement, fresh service provenance, bounded MSI version capture, and validated installer and native updater transactions.
- Shared documentation updated and pinned to a published source revision, with integrity-checked packaged resources.

## Downloads and provenance

Linux x86_64, macOS Apple Silicon, and Windows x86_64 bundles are built from the same immutable stable tag on `main`. Windows also provides an MSI installer; macOS also provides a DMG. Each platform includes exact source/version metadata, and every payload has a SHA-256 sidecar.

Private `.neoism` configuration and memory, local histories, and ignored build artifacts are not part of the source release.
