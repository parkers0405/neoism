# Neoism v0.7.150

This stable update includes the complete post-v0.7.149 source batch for the Rune app, Agent runtime, daemon protocol, embedded hosting SDK, and shared documentation.

## Rune app

- Refine Agent activity indicators, transcript restoration and history editing, attachment handling, composer context accounting, and tool-card grouping and diffs.
- Extend slash-command panels for goals, tasks, plans and usage, with corresponding daemon and protocol support.
- Add editor Git integration and improve server selection, settings, theme palettes, and Home terminal behavior.
- Introduce Neoism Dark and Neoism Light defaults and configurable first-party pixel flames on the Home and Agent wordmarks, preserving the existing click effects and reduced-motion behavior.

## Agent runtime and embedding

- Improve run handoff, cancellation, recovery, event-writer ownership and streaming lifecycle handling.
- Add an owned, listener-free Rust EmbeddedAgent host using the existing Agent engine and API router, including authentication, streamed responses and explicit shutdown.
- Add an optional native Node.js embedding binding and TypeScript SDK entry point, with examples and integration tests. The native SDK binding is built separately; desktop bundles do not automatically install an npm package or publish it to a registry.
- Publish shared hosting guides for embedding, Docker and Durable Objects alongside the existing handbook and API documentation.

## Packages and verification

Linux x86-64, macOS ARM64 and Windows x86-64 packages are built from the same immutable stable tag on main. Platform CI builds the Rune app and services, packages the application, and validates platform-specific installers and updater transactions. Payloads include SHA-256 sidecars and exact source/version metadata.

Automated checks and platform packaging do not imply exhaustive live-provider, GUI, or cross-device validation. Preserve a consistent database backup before upgrading; existing database downgrade cautions remain applicable. Private .neoism files and ignored local binaries are excluded.
