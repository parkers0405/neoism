# Neoism v0.7.144

This stable update improves remote interactivity, terminal output handling, collaboration presence, and MCP authorization.

## Changes

- Enable TCP_NODELAY for direct TCP connections to the workspace daemon and agent server, keeping small interactive and streamed updates responsive.
- Coalesce terminal output bursts on presentation frames with a timer fallback for hidden windows, while preserving immediate first echo, bounded buffering, replay offsets, query-response boundaries, and flush ordering before input or directory changes.
- Avoid repainting document views for unchanged peer heartbeats or unrelated buffers, and keep presence-only updates from invalidating editor recovery. Unchanged local cursors no longer schedule redundant presence work.
- Restrict MCP actions to authorization while credentials or client registration are required.
- Route system-scoped MCP browser OAuth callbacks through the existing one-time-state validator without requiring a browser bearer token, preserving callback HTML while retaining authentication for other routes and methods.
- Add regression coverage for terminal batching/replay, presence repaint and recovery behavior, MCP action gating, and callback scope/authentication handling.

## Downloads and provenance

Linux x86_64, macOS Apple Silicon, and Windows x86_64 bundles are built from the same immutable stable tag on `main`. macOS includes a DMG and Windows includes an MSI. Every payload has a SHA-256 sidecar and every platform includes exact source/version metadata. The unchanged shared documentation remains pinned to its published revision.

Private `.neoism` configuration and memory, local histories, and ignored build artifacts are excluded from the source release.
