Editable Git review foundation shipped in follow-up work: shared GitDiffView no longer edits patch text. It borrows a canonical full-file CodePane via render_with_editor; CodeBuffer is document truth. Shared editor/code/projected.rs renders syntax/selection/caret only into host-supplied ProjectedCodeRows (zero-based source lines, line-local UTF8 byte_start/end, absolute y, continuation indent_cols). CodePaneGeometry.projected_rows + projected_hit_position reject old-only/spacer/hunk gaps; normal full-editor rendering resets projection. build_review_diff(base,current,context,ensure_source_line) in code/gitdiff.rs uses bounded diff and includes caret excerpts so Vim full-document motion can reveal unchanged lines outside prior hunks. diff_card::source_fragments shares actual wrapping source ranges/indent; PaintParams.hide_code_text suppresses duplicate right-column glyphs while preserving tints/gutters/hatching. Native CodePane caret is drawn by active-code trail overlay; do NOT force a second local caret over it. GitDiffView.editing_path is keyboard-focus-gated; document_path stays attached after header blur so canonical unsaved text keeps painting instead of falling back to disk patch. Native manager active_code_pane helpers resolve hidden context-owned canonical owners; existing owner reused acrossgrids, wrong workspace/provenance and existing Markdown owners refused visibly. Web active/parked CodePane reuse does not create ordinary file tabs; parked per-document CRDT binding retention requires preserving dirty baseline/undo and inbound updates (final safety verification ongoing when this entry written). Lazy baseline: ReadBase{path}->BaseFile{path,text}; GitDiffIo.load_base/request_base; panel request_diff_base/getter/error/pending/host_set_base_text; full HEAD exact UTF8 <=2MiB, missing/unborn path empty, binary rejected. Host baseline errors disable edit focus and show red notice; no invisible typing into a failed preview. Parser ignores EOF metadata and binary metadata, only actual +/-/space source rows gain positions; malformed zero positions aren't editable. Native diff read uses literal pathspec/no-extdiff/no-textconv and Added files compare against /dev/null for first commit. Stage/Restore hover headers + compact toolbar functional. Native exact GitStagePlan targets use canonical-save barrier and one mutation, all sidebar/menu/keyboard/folder/Lua entrypoints route through it; Unstage bypasses save. Web every Stage/Restore provider envelope uses synchronous WASM preparation after a JS microtask to avoid reentrant borrow; current dirty source queues save then Saved-stage, dirty nonactive/Markdown owners refuse with save-first. Missing gate bridge fails closed. Restore protocol restores WORKTREE FROM INDEX, preserves staged text, validates exact tracked file/literal paths, requires UI confirmation, refuses untracked and unsaved canonical owners. Saved is still unversioned broadcast; exact concurrent-peer acknowledgment correlation remains a pre-existing protocol limitation. No release builds or commits. Shared Git58/editor119/widgets14/scroll74/history2 tests passed, daemonGit14 passed during integration. See git_commit_view.rs for footer/history feature.
