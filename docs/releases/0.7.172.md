# Neoism v0.7.172

- **Simpler phone pairing on macOS:** Connect your Mac and iPhone to the same Tailscale network, select **Pair a phone** in Neoism, and scan the short-lived QR code. No separate pairing password or daemon restart is required.
- **Linux release fix:** The photo-attachment regression test now verifies that a paired chat uses the host default folder and waits for the new thread before sending the photo.

This desktop release targets Linux x86_64, macOS Apple Silicon, and Windows x86_64. The iOS app is distributed separately.
